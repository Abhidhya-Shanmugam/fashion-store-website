# FashionHub ✨

A modern and stylish clothing website built using HTML, CSS, and JavaScript. This project features a responsive multi-page design with attractive UI, hover effects, animations, product showcase, search bar, shopping cart icon, and contact form popup.

---

## 🚀 Features

- Modern Homepage Design
- Separate Shop Page
- Contact Page with Popup Message
- Stylish Product Cards
- Hover Zoom Effects
- Glowing Card Animation
- Search Bar
- Shopping Cart Icon
- Social Media Footer
- Responsive Layout

---

## 💻 Technologies Used

- HTML
- CSS
- JavaScript
